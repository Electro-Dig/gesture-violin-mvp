# 弓弦 · Gesture Violin

一个完全在浏览器中运行的单手弦乐交互 MVP：自由演奏时，手掌上下选择音高、左右移动驱动琴弓；移动速度同时控制音量、音色亮度、琴弦辉光与松香微粒。项目也包含一套接近音乐游戏的方向节奏演奏模式。

在线体验：<https://gesture-violin-lab-664.netlify.app/>

## 交互方式

首页可进入两种演奏体验：

- **曲目演奏**：从《欢乐颂》与《D 大调卡农》的原创精简编配中选曲。旋律音高由谱面自动给出，不再要求手追逐高低位置；音符条抵达固定红线时改变左右拉弓方向即可。有效拉弓才会推动旋律与伴奏，换弓处有约 280 ms 的宽容时间。演奏结束后按方向节奏、拉弓连贯与力度表现给出百分制和星级。
- **自由演奏**：保留原有的八音单手乐器体验。

- 上下移动：自由演奏时，在 C 大调五声音阶扩展出的 8 个友好音符间选择音高；曲目演奏时不影响旋律音高。
- 左右移动：产生拉弓动作；只有横向速度超过阈值才发声。
- 停止移动：保留当前音高，但自然收声。
- 离开画面：立即释放声音，避免卡音。

页面提供三种输入模式：

1. **摄像头**：MediaPipe Hand Landmarker 在本机实时识别一只手。
2. **鼠标排练**：按住并拖动，走与摄像头完全相同的手势解释和音乐映射链路。
3. **自动演示**：访问 `/?demo=1` 使用可复现的模拟手势，仅用于远程视觉验收，并会在界面中明确标注。

## 技术组成

- TypeScript + Vite
- Three.js 程序化原创小提琴、琴弓、琴弦和粒子
- MediaPipe Tasks Vision，本地托管 WASM 与手势模型
- Web Audio API 实时合成：双振荡器、弓噪声、滤波、包络、颤音、短延迟，以及随拉弓弹性时间推进的程序化和弦伴奏
- Node test runner + tsx，用纯逻辑测试固定手势、音阶、动画和声音参数

没有使用 Viola the Bird 的代码、模型、纹理或录音。本项目只借鉴“移动琴弓来演奏”的一般交互范式；3D 几何和音色均由本项目程序化生成。《欢乐颂》和《D 大调卡农》均为公版作品，本项目只使用自行录入的音高关系与原创简化伴奏，不包含第三方录音或现代编曲资产。

## 浏览器与权限

- 推荐桌面版 Chrome 或 Edge 的近期版本。
- 摄像头在公网只能通过 HTTPS 使用；`localhost` 可用于本地开发。
- 浏览器要求用户点击后才能启动 Web Audio，因此自动演示默认无声，点击“启用声音”即可。
- Safari 可运行主要 WebGL/Web Audio 内容，但本 MVP 的摄像头路径以 Chromium 浏览器为首要验收目标。
- 摄像头画面只在当前浏览器标签页内分析，不上传、不录制。

## 已知边界

- 当前是程序化合成的“弦乐感”音色，不是采样级真实小提琴；引导演奏使用短版教学编配，不是完整乐章。
- 单目摄像头容易受逆光、遮挡、运动模糊和低帧率影响；界面提供鼠标排练作为显式降级路径。
- 单手方案优先追求可玩性：纵向位置被量化到友好音阶，不模拟真实指板指法。
- ToF、WebHID 或 Web Serial 尚未接入此 MVP，但输入层已经统一为标准化手帧，可在不改动音乐、3D 和音频层的前提下新增适配器。
